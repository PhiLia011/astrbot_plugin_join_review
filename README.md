# astrbot_plugin_join_review 入群审核

只做一件事：**有人申请加群时，在群里发一条通知，并把申请人的资料卡一起带上**，方便群主 / 管理员判断。

处理方式：**引用那条通知**，回复「同意」「拒绝」或「拉黑」。

> 入群之后的自动开盒由 **box 插件**负责，本插件不参与，也不提供盒查询指令。

## 用法

有人申请加群后，群里会收到：

```
<申请人的资料卡图片>
有人申请加群，请确认是否放行

QQ：123456789
昵称：某某

引用本消息回复「同意」「拒绝」或「拉黑」
```

长按 / 右键**引用这条消息**回复：

| 指令 | 效果 |
| --- | --- |
| `同意` / `通过` / `批准` | 通过加群申请 |
| `拒绝` / `驳回` / `不同意` | 拒绝加群申请 |
| `拉黑` / `黑名单` | 拒绝申请 + 记入黑名单 |

也支持 `同意 123456789` 或 `@某人 同意`。

只有**群主、群管理员**（或配置里的额外管理员、AstrBot 管理员）能操作。

## 资料卡的来源

申请阶段对方还没进群，只能走**陌生人接口**（`get_stranger_info`），所以卡上只有公开资料。

正式入群后 box 插件再开的那次，可以走**群成员接口**（`get_group_member_info`），会多出群昵称、群头衔、群身份、加群时间等信息。

## 配置

| 项 | 说明 |
| --- | --- |
| 启用入群审核 | 总开关 |
| 加群申请时附上资料卡 | 关掉就只发文字通知 |
| 加群申请通知文案 | 支持 `{user_id}` `{nickname}` `{group_id}` `{comment}` |
| 同意 / 拒绝 / 拉黑后的回复 | 三套文案 |
| 拉黑生效范围 | 仅本群 / 全局 |
| 拉黑时同时拒绝其再加群 | `set_group_kick(reject_add_request=True)` |
| 黑名单用户入群时自动踢出 | 拉黑的人如果进群会被移出 |
| 允许普通群成员也能处理 | 默认关闭，只允许群主/群管理员 |
| 允许普通成员处理的群（白名单）| 留空=全部群允许 |
| 禁止普通成员处理的群（黑名单）| 优先于白名单 |
| 额外可审核的人员 | 额外放权的 QQ |
| 生效群聊白名单 / 黑名单 | 控制哪些群启用，黑名单优先 |
| 信息显示选项 / 信息脱敏 | 资料卡上显示哪些字段、是否脱敏 |

## 数据

```
data/plugin_data/astrbot_plugin_join_review/blacklist.json

```

## 说明

- 基于 OneBot v11 的 `request.group.add` 事件；拉黑后的拦截用到 `notice.group_increase`。
- 通过 / 拒绝走 `set_group_add_request`，踢人走 `set_group_kick`，机器人需要是群管理。
